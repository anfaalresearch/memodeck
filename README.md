# MemoDeck

MemoDeck is an offline-friendly study guide for learning inventors and inventions through mnemonics and active recall.

## Live site

[Open MemoDeck](https://anfaalresearch.github.io/memodeck/)

## Run locally

Open `index.html` in a browser. No build step is required.

## GitHub Pages

This static HTML, CSS, and JavaScript site is deployed automatically through GitHub Actions.
