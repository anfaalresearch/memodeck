# MemoDeck

MemoDeck is an offline-friendly study guide for learning inventors and inventions through mnemonics and active recall.

## Run locally

Open `index.html` in a browser. No build step is required.

## GitHub Pages

This is a static HTML, CSS, and JavaScript site. Publish the repository from its `main` branch using GitHub Pages, or use the included Pages workflow when GitHub Pages is configured for GitHub Actions.
